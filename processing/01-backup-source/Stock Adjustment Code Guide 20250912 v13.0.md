Store Adjustment Codes Guide

Introduction

With continual work towards improved data integrity and simplified processes, a range of adjustment codes are available in the 'Adjust Stock Levels' menu on PDT devices which include the listed in this guide. This guide steps through when and how to use these codes using a PDT device to make the stock adjustment. This will ensure your stock levels are accurate and assist National Office with accurate reporting in identifying where stock loss occurs.

Manager-Only Adjustment Codes on PDTs

Certain adjustment codes on the PDTs are restricted to manager access only. This is because these types of adjustments require investigation and must be performed by a manager, as incorrect adjustments can compromise the store's stock integrity.

These restricted adjustments include:
• Gapscan
• Adjust Item
• Online Exceptions

These fall under store-initiated integrity checks, specifically Code 20 and Code 62.

Any adjustments over $100 for Code 20 and Code 62 must be approved by the Store Manager on the Shrinkage Report.

Important Guidelines:
• Managers must not grant team members access to perform these restricted tasks.
• All adjustments must be completed under the correct team member's login.
• Login credentials must never be shared.
• Team members who are rostered as a supervisor and performing Higher Duties may have their access temporarily increased in the PDT user system for the duration of their higher duties, as they are being paid to complete those responsibilities.

Stock Adjustment Code Listing

Report Product Loss Codes

Code | Description | Rules for Use

Code 7 | Inner Carton | The 'Inner Carton Adjustment' is used in the decanting process, when there is a discrepancy with the inner carton quantity and the 'issued quantity' marked on the carton.

Code 8 | DC Soiled & Damaged | The 'DC Soil and Damaged' stock adjustment is used when a store has identified units that are soiled and damaged during the decanting or receiving process, which needs to be written off.
If a store receives a damaged manifest from the DC with either with or with good, stores can use this adjustment code option instead of option 2 (Write Off) to adjust out manifested stock.

Code 11 / WO | Write Off | A write off adjustment is used where the items are faulty, soiled or damaged and cannot be repaired, returned to supplier, sent to the CRC or sold at a reduced sell price.

Code 21 / EP | Empty Packets | An empty packet adjustment is where it is evident that the merchandise has been stolen, for example an empty confectionary packet or an apparel tag concealed.

Code 50 | Out of Date | An 'Out of Date Write Off' adjustment is used where out of date stock is found and Kmart does not have an agreement with the supplier for compensation e.g., chips, cosmetics, chocolate, personal care etc.

Code 09 | Code 09 = Display Stock | A 'Display Stock' adjustment is used to adjust items to the correct reporting line for display items. It is used for store electrical displays only and must be written off.

Code 27 | Water/Fire/DMG | A 'Water/Fire/Theft DMG' adjustment is used to adjust items to the correct reporting line that are damaged due to water, fire or theft. It is used for stock that are damaged due to water, fire or theft and must be written off.

Code 31 | Store Staff Uniforms | A 'Store Staff Uniforms' adjustment is used to adjust items to the correct reporting line for team member uniforms. It is used for Team Member uniforms and must be written off. The main item used under this adjustment code is Safety Steel Cap Footwear.

Code 53 | Known Theft (External) | A 'Known Theft' adjustment is used to adjust keycodes to the correct reporting line for items missing due to known theft. This adjustment code will require approval from Profit Protection, it will be used for stock that is missing due to known theft and must be written off.

Code 54 | Variance in ITC | A 'Variance Qty in ITC' adjustment is used to adjust items that have been identified to be of a different quantity to what is listed in the SCM details, and the sending store has been contacted and unable to resolve the difference.

Code 57 | Known Theft (Internal) | This adjustment code will require approval from Profit Protection, it will be used for stock that is missing due to internal known theft from a team member incident and must be written off.

Store Adjustment Codes Guide

Code 58 | NZ Customer Returns (NZ ONLY)
A 'NZ RLO returns' adjustment is used to adjust items to the correct reporting line for items that are refunded and damaged that cannot be resold or claimed.

Code 59 | Store Use
A 'Store Use' adjustment is used to adjust items to the correct reporting line for store use items. It is used for store use and must be written off.
Refer to the Store Use Policy and Store Use Process for additional rules when applying this code.

Code 60 | Missing Qty in Manifest
A 'Missing Qty in Manifest' adjustment is used to adjust keycodes to the correct reporting line for items missing due to missing items on a manifest that is not claimable and must be written off.

Code 63 | Mouldy Stock
A 'Mouldy Stock' adjustment is used to adjust keycodes to the correct reporting line for mouldy items. This will be used when stock has mould and must be written off.

Integrity Check Codes
Code | Description | Rules for Use

Code 51 | Integrity Checks (high Count)
A list of departments that require a count will be listed in the 'National Office Adjustments' screen. Team Members are required to count the stock and enter a quantity.

Code 20 & 62 | Store Initiated Integrity Checks
The 'Code 20' adjustment is used to complete gap scan counts and 'Code 62' adjustment is used for online exceptions and anything else other than gap scans.

Claimable Codes
Code | Description | Rules for Use

Code 10 | Store Claims
Code used to process adjustments where Kmart have an agreement with the supplier to raise a claim. Where Kmart do not have an agreement with the supplier, the buyer should be contacted before proceeding with the claim.

Code 52 | Out of Date
The 'Out of Date – Code 52' function is used where out of date stock is found and Kmart do have an agreement with the supplier for compensation (e.g., Lindt Chocolate).

National Office Directed Codes
Code | Description | Rules for Use

Code 40 | Claimable
The 'NOD Claimable – Code 40' function is used for product recall items, where Kmart is able to receive compensation from the supplier.
National office will instruct stores, via store communications on Kit if this occurs, providing instructions on when to use this code and required actions for the actual stock.

Code 56 | Non- Claimable
The 'NOD Not Claimable Code 56' function is used for product recall item/s where Kmart cannot get compensation from the supplier.
National office will instruct store, via store communications on Kit if this occurs, providing instructions on when to use this code and required actions for the actual stock.
