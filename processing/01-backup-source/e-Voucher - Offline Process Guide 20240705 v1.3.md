e-Vouchers: Offline process

The following table explains the process of what to do when your e-Voucher system is offline. While in offline mode, there are only a couple of clues that you are offline,

• First clue- when redeeming on e-Voucher the sales receipt the ID number will be all zeros.
• Second clue is that when issuing an e-Voucher the message on the bottom of the receipt says "voucher only valid in this store" and 9999 appears in the voucher number.

See below for more detail about what to do for various scenarios.

Scenarios

An online e-Voucher is redeemed while a store is offline. (any store) | The first time an individual e-Voucher is redeemed in offline, the register will display the following message: EVoucher temporarily offline, please check the expiry date on the voucher, enter e-Voucher balance. (a green pop up message)

You will need to call the issuing store to determine the balance of the voucher.

Issuing store is to complete an e-Voucher balance transaction using the voucher number given to them by the redeeming store and tell the redeeming store what the balance on the voucher is.

Note: it is important to confirm the e-Voucher balance with the issuing store as there is the potential for the e-Voucher to have no value on it.

Type in the amount and press enter.

If the voucher is over $60 | A message will display on the screen (orange pop up message)
Phone for authorisation – 1800 033 534

When this message displays a receipt will print with the details of the e-Voucher so that you can call support. The screen will stay with this message until you enter the amount given by store support and press enter.

An offline voucher is redeemed while still offline (same store) | No change to current online process.

An offline voucher is redeemed in online (same store) | No change to current online process.
