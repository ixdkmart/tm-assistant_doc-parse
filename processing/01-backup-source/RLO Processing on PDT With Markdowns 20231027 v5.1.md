Processing RLO on a PDT

The RLO function via a PDT allows the capturing of detailed information on reasons for customer returns and simplifies the process of Soiled and Damaged (S&D) merchandise. The RLO function is located on the PDT under the 'Receive and Dispatch' menu, with 5 RLO menu options.

RLO Menu Options

Menu Option | Function
---|---
Assessment | Assists in the assessment of soiled and damaged or faulty merchandise to determine the appropriate action to achieve the best commercial outcome.
Dispatch | Used to dispatch all SCMs created through the RLO assessment function.
Item Enquiry | Used to check scan a pallet/item combination to confirm how many units of an item have been scanned against the SCM. This assists with identifying where items have been placed on a pallet without being scanned or vice versa.
Remove | Allows you to scan an item that was incorrectly processed through RLO assessment and remove it from the SCM contents.
Avoid SCM | Allows you to void an SCM that was incorrectly processed through the RLO assessment function.

RLO - Assessment
The 'RLO Assessment' function is used to check scan each soiled & damaged or faulty item and determines appropriate action to achieve the best commercial outcome for the store and Kmart.

Depending on the status of the item scanned, the RLO Assessment screen will display informative messages advising the next course of action. There are 6 different outcomes that could occur during RLO process:

1    Item is on recall                                          2    Claimable pallet (adjustment code 41)***
3    Written off (adjustment code 11)                4    Claimable pallet (adjustment code 3)***
5    Salvage project (adjustment code 3)          6    Place onto the S&D clearance end
***Includes markdown option

Step | Action
-----|--------
Step 1 | In the 'receive and Dispatch' menu under RLO, select 'Assessment'.
Step 2 | Scan the item from the RLO area, to be assessed. The PDT will prompt you on next steps.
Info | A help screen can be viewed by selecting the '?' icon.

Printing S&D Labels for Additional Markdowns

If additional markdowns are required to be printed for soiled and damaged items, the barcode on the original S&D label can be scanned. The label will display the number 1, which indicates the item has only been marked down one time.

Step | Action
-----|--------
Step 1 | When scanning the barcode on the S&D label with a PDT, the RLO Assessment screen will display with the items previous markdown information including the markdown reason and date.
Step 2 | To print an additional markdown S&D label, select the item form the list displayed. The RLO Markdown screen will display with a default markdown price of 50% on the previous markdown. Select the portable printer used to print the markdown labels, then select 'Print'.
Info | The description and reason for the previous markdown will remain on the screen with the only change to the price at an additional 50% markdown.
Step 4 | The markdown label will print with the new markdown price, including the date the label created and the number of markdowns. In this example this is the second markdown, so a number 2 displays.

RLO Adjustments are automatically adjusted off as follows:

RLO Assessment - Online Exclusive Products
Online exclusive products returned to a store and are not able to be resold, can now be processed as a RLO claimable item.

IMPORTANT: Online Exclusive products should only be sent to RLO if not in saleable condition.
If the online exclusive product is in resaleable condition:
• Returned with no damage, it should be placed onto the shop floor and sold at full price.
• Returned with damage but in saleable condition, place into the clearance area and markdown as per the markdown process.

Step | Action
Step 1 | Log into the RLO assessment tool on a PDT.
Step 2 | Scan the barcode on the POS product return receipt.

Step 3
On the next screen a message will display "Could this item be sold in the Mark-down area?"
• If Yes – Follow the markdown process.
• If No – Follow the screen prompts to scan the claimable pallet SCM, then scan the online exclusive product barcode.

Step 4 | Place the online exclusive item into the claimable pallet

Info
If an online exclusive item returned to store cannot be resold however is too large to add to the RLO claimable pallet safely, contact your Online Fulfilment Coordinator who can assist in organising collection of the item.

Example 3
(Claimable + Dispose of Item)

From the 'RLO Assessment' screen scan the barcode on the POS product return receipt. The PDT will display a message to advise the item is claimable (disposal code of 7) and has a unit cost less than $2.00. It is not in the holding for testing list.

Hold for Testing:
Hold for testing is flag that is setup for the TIC (RLO) to use when the stock arrives at the TIC from stores, they do not to send it to the supplier for a claim, like they usually do. Instead, the TIC will engage a 3rd party to investigate the root cause.

Example: There is a batch of heaters being returned by stores and rather than send it directly onto the supplier for a claim, they will engage another 3rd party to investigate the root cause.

Place the item in the write off bin and select 'Finish'. The system will write off the stock under adjustment code WO – code 11.

• Is a POS reason code of 20 or 25
• Is a Clothing, Footwear, Christmas, or Heating item

Scan the claimable pallet. A message 'Claim Successful' will be displayed and the stock is written off under adjustment code 3.
