ITC-SCM best practice

• If Boxes are going to be sent invaluably each box should have its own SCM label

• Each pallet or FB2 that is being sent should also have its own SCM label (group of boxes or items)

• You should start a new SCM when sending more than 1 box, or pallet/FB2

• The SCM label should be clearly visible on the outside of each item

• Signs should be clearly visible and have the sending and receiving store listed as an ITC

• Store to Store tape should be used.

• If backloading an ITC the W52 should list the ITCs QTYs you are sending back on the truck.

Send Interstore Transfer

The 'Send interstore transfer' function (previously known as 'Despatch' on old PDTs) allows the transfer of merchandise from one Kmart store to another Kmart store via an electronic transfer system utilising the PDT units and back office system

This function has now been added to the 'Receive and Dispatch' menu on the new PDTs.

The process has streamlined to allow items to be added to the SCM and then submitted to the sending store without creating a new shipment and a performing a dispatch of the SCM. (Note: The create CSCM option has also been removed)

Send an Interstore Transfer

> From the 'Receive and Dispatch' screen select 'Send interstore transfer'

The 'Send Interstore transfer' screen will be displayed

> Enter the 'store number' or 'name' and select the store from dropdown list

> Scan an 'SCM'

Direct to Store Receiving

The 'Direct to Store Receiving' function (previously known as 'ITC/DTS Recv' on old PDTs) will allow ITC's and 'Direct to Store Receipts' to be receipted.

This function has now been added to the 'Receive and Dispatch' menu on the new PDTs.

Receipt an ITC

➢ From the 'Receive and Dispatch' screen select 'Direct to store receiving'

The 'ITC & Direct to store receiving' screen will be displayed

➢ Scan the SCM on the carton delivery

A message will be displayed the ITC receipting has been receipted.

➢ Select 'Finish' to exit

Note: Help on each screen can be viewed by selecting the '?'

[Red text box content:]
Scan the SCM code on the carton
If the code is missing try searching the system for expected shipments for a full list of SCM's expected. You can also enter the SCM in here

Receipt a Supplier Delivery – Carton Level

➢ From the 'Receive and Dispatch' screen select 'Direct to store receiving'

The 'ITC & Direct Supplier receiving' screen will be displayed

➢ Scan the SCM carton label

The supplier details screen will be displayed

This example has 1 SCM that does not require item count.

Items marked for carton receipt can also be individually counted 'if required' by selecting 'Count Items'

➢ Select 'Accept delivery' to receipt the SCM at carton level (OR 'Count items' to override and count all items in the carton)

A message 'Carton has been accepted' will be displayed

➢ Select 'Finish' to exit or continue to scan further SCM's if required.
