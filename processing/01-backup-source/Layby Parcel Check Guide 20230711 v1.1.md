Layby Parcel Check Guide

Sign Into POS/CC
Step 1: Go to POS Controller (NSE/PC menu)
Step 2: Log in with (Alphabet) longer POS password and 3-digit register ID
Step 3: The main log in screen will appear, log in again with same password (POS not register)

How to Print the Layby Parcel Check
Step 1: Press 1 and enter for "Sales Application"
Step 2: Press the F8 Key for accounts
Step 3: Press F3 that will go back to the menu
Step 4: Type in 5 and enter for "Layby/Store Account Reports"
Step 5: Type 3 and enter for "Layby outstanding for stocktake"
Step 6: Type * and enter for all locations
Step 7: Type Y to begin printing

How to complete the layby parcel check/stocktake

Step:
- Check each charge/layby Number for the location and confirm no parcels are missing
- Any parcels in the wrong location should be returned to listed location

Note:
- Any missing parcels should be notated and replaced if possible. (see Info for how to view details)
- Any parcels without a location should be checked and confirm if they are canceled to be returned to shopfloor (see Info for how to view details)

Info:
To view layby/parcel details, follow step 1 and step 2, this will bring up the layby screen. Press 1 enter and type in the charge/layby number to see layby/Customer/Items/Cancellation status.
