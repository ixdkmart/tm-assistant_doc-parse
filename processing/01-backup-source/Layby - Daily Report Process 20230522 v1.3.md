## Page 2

What should I look for?

Deleted Incomplete or Cancelled Charges

This section of the report lists all laybys that have been cancelled the day before. It allows the Line Manager to review the cancelled charges to ensure that they are all legitimate transactions.

All entries listed as a Customer Cancel have the relevant receipts attached:
- Store use pick-slip attached
- Original parcel receipt attached
- Authorised section of the pick-slip is signed

Note: Store Cancellation receipts should not be attached to this report. They should be attached to the Overdue Layby Report.

Items Deleted From Charges

This section of the report documents any occasion where team members have removed any item from a layby. This process should only be used for the removal of recall items.
- Relevant receipts attached with a Manager's signature
