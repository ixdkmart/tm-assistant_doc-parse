## Page 1

PDT Store Markdown Labels

The 'Store Markdown' function has now been added to the home screen on the PDTs and can be used to print orange markdown labels from the portable printer. This function is available for managers only.

Clearance guides have been linked below; these should be reviewed on when a store markdown can be used. Markdowns outside of the below process should be approved by your Zone Manager.

Khub Smart Apparel Clearance Guide Located in: Stores > Merchandise > Layouts > Khub

Smart Apparel Clearance Guide_V2.1 Located in: Stores > Operations > Shop Floor

Store markdowns on the PDT can only be actioned with an orange pathfinder label, these can be ordered from Bluestar: KMA9502636 - Kmart Labels - (Orange) Pathfinder for Portable Printer. The yellow pathfinder label is not compatible with the portable printers.
